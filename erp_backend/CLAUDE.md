# المشروع
ERP API بـ ASP.NET Core + SQL Server + EF Core. الواجهة منفصلة (React + Vite).
مطوّر واحد. العملة الأساسية: IQD. رسائل المستخدم بالعربية، الـ Logs بالإنجليزية.

# اقرأ أولاً، بهذا الترتيب
- @docs/STATE.md                 — أين وصلنا. لا تُعد بناء ما هو منجز.
- @docs/ROADMAP.md               — ما التالي وبأي ترتيب. مرجع أرقام الأقسام (§4.1، §5.4…).
- @docs/ERP-CORE-RULES.md        — البيانات المالية. له الأسبقية عند أي تعارض.
- @docs/backend-design-rules.md  — بنية الطبقات والتسمية والأخطاء.

# قبل أي جدول أو كود
1. اعرض الخطة أولاً. لا تكتب كوداً قبل موافقتي الصريحة.
2. طبّق قائمة الفحص (ERP القسم 13) واذكر نتيجتها بنداً بنداً.
3. اذكر أرقام القواعد التي طبّقتها (مثل R-AMT-02).
4. إن خالف طلبي قاعدة [صارم]، ارفض واذكر رقمها قبل التنفيذ.
5. حدّث STATE.md في نهاية كل مهمة.
